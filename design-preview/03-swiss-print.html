+

[ 01 · 配色 PALETTE ]

未漂白道林纸 #F4F4F0 + 碳素黑 #050505；航空警示红 #E61919 是唯一强调色， 只用于编号、删除线、关键数据与主按钮 hover。无渐变、无阴影、无圆角。

[ 02 · 版面 LAYOUT ]

1120px 刚性网格，全幅水平线切分；宏观标题 clamp 到 4.4rem、压缩字距 -0.05em， 与 11px 等宽元数据形成极端对比；数据密度与大面积留白交替（bimodal density）。 1px 边框全部由 gap:1px + 对比底色生成。

[ 03 · 按钮 BUTTONS ]

纯直角，零圆角。主按钮实心黑，hover 翻红。状态为方形描边标签， 待播=实心黑、已播=描边、略过=虚线灰。次要动作用等宽字小方块。 ASCII 装饰：>>> [ ] + 十字定位符。
