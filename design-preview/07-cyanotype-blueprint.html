[ 配色 PALETTE ]

普鲁士蓝 #0B2947 底 + 淡青线条 #8FD6F0 / 亮青 #C6ECFF。单色系（蓝）， 靠线的透明度分层，不用任何第二种色相。

[ 版面 LAYOUT ]

1140px 制图板：固定网格底纹、四角裁切标记、顶部坐标刻度带。 条目是蓝图记录表（编号 / 内容 / 操作）三栏。等宽字标注尺寸与编号，窄体大写做标题。

[ 按钮 BUTTONS ]

全部直角描边。待播=实心点击翻白，已播=双线框（○），略过=虚线框（—）。 装饰用十字定位符 + 裁切角 + >> 箭头。hover 时标题带青色辉光。
