共享新闻池 · 使用手册

多人协作的实时待播新闻池 ｜ 本地优先 · 零构建 · 开源(MIT) · 一键启动

一、这是什么

每人登录后，把自己准备播的新闻丢进同一个「池子」。系统会：

  • 实时同步给所有在线的人（谁都不能重复报同一条）；
  • 发现重复时立刻提示「这条 X 分钟前已经有人加了」；
  • 一键联网核查：搜一下有没有其他来源报道同一件事；
  • 播完打勾，并记录是谁播的；还能按人、按天导出清单。

数据全部保存在你自己的电脑上，不上传任何云服务，不需要注册账号即可使用。

二、三种用法（选一个）

一台电脑当「主机」，其他人用浏览器访问它 —— 主机配置一次，访客什么都不用装。

用哪种适合访客怎么进成本 / 隐私
① 局域网（推荐）同一办公室 / 同 WiFi浏览器打开 http://主机IP:3210免费；数据不出内网，最私密
② 内网穿透隧道三个人不在同一地方打开一个公网网址（自带 HTTPS）免费；数据经加密隧道
③ 云服务器 VPS要 24 小时在线打开固定网址每月少量费用；数据存在第三方服务器

详细步骤（含防火墙、HTTPS、安全注意）见仓库里的 部署指南.md。

三、快速开始（主机做一次）

  1. 装 Node.js 18+：https://nodejs.org/
    （Windows 也可以直接双击 start.bat，检测不到 Node 时会用 winget 帮你装。）
  2. 启动：Windows 双击 start.bat；macOS / Linux 运行 ./start.sh。
    首次会自动安装依赖，约需一两分钟。看到「共享新闻池 已启动」就成了。
  3. 浏览器会自动打开 http://localhost:3210。
    那个黑色窗口就是服务本身，关掉它 = 停止服务。
  4. 让别人也能访问：查本机局域网 IP（Windows 运行 ipconfig 找「IPv4 地址」，一般是 192.168.x.x）， 然后让访客打开 http://192.168.x.x:3210。
    若连不上：Windows 弹出防火墙提示时选「允许」；或在管理员命令行放行端口： netsh advfirewall firewall add rule name="news-pool" dir=in action=allow protocol=TCP localport=3210
⚠️ 正式使用前必做：改掉默认密码。 默认账号 alice / bob / carol，密码均为 123456； 成员模式（管理员）密码 admin888。要暴露到局域网之外时，尤其必须先改。

四、给访客（那两位只需 3 步）

  1. 打开网址：浏览器地址栏输入主播给你的网址，回车。
  2. 登录：输入主播给你的账号和密码。
  3. 开始用：看到新闻清单就成了。

打不开时：确认和主播在同一个 WiFi（局域网方式），或者向主播要最新网址。

五、常用操作

想干什么怎么做
加一条新闻点「加新闻」，粘贴链接或直接写标题；也可全页拖拽、页面空白处 Ctrl+V
自动抓标题粘贴网页链接即可；X / Twitter 链接会自动取回推文正文
标记 待播 / 已播点新闻右侧的状态胶囊一键切换（会记录是谁播的）
标重点点 ☆；顶部「★ 重点」标签可只看重点
核查真伪点开该条 → 「核查」，会列出其他来源的同题报道
写备注添加时可直接填；之后在条目的 ⋯ 菜单里「加备注 / 改备注」（备注里的网址可点开）
移动日期 / 略过条目 ⋯ 菜单里；日期分组右侧可把当天未播出的整体顺延
复制 / 导出⋯ → 复制「标题+备注+链接」；顶栏「导出当天」可按人导出清单
看统计顶栏「统计」→ 月历网格，逐日查看每人「准备 / 已播」条数
换外观顶栏「外观」→ 10 套主题任选，立即生效并记住

六、界面外观（10 套主题）

顶栏「外观」里挑一套，点一下立即生效并自动记住。内置：经典·暖灰、暗调编辑、暗夜玻璃、工业蓝图、战术终端、软结构、暖金奢品、氰版蓝图、双色丝网、层叠卡片、赛博霓虹。

  • 只存在你自己的浏览器里（localStorage），别人完全不受影响；
  • 不加载任何在线字体 —— 守住「只发少数几类外部请求」的承诺。

七、安全与隐私（可自行核验）

本程序源码完全开放，所有逻辑都在 src/ 里，可逐行检查。

  • 数据全部存在本地：新闻、账号、密码（bcrypt 哈希）都写在 data/ 目录，不上传任何服务器；没有埋点、没有遥测。
  • 只依赖 3 个运行时包：bcryptjs、better-sqlite3、ws（均为宽松的 MIT/ISC 类许可证）。
  • 只有 4 类主动外联，且都必须由你亲自触发：抓网页标题、核查搜索（DuckDuckGo / Bing）、X 取正文。

自己验证的三种方法

  1. 跑自查脚本：npm run audit —— 打印依赖清单、所有外联点、域名白名单与危险模式检查。
  2. 断网测试：关掉网络后，除「核查 / 抓标题」外功能照常 —— 说明它不偷传数据。
  3. 亲眼看它连了谁：浏览器按 F12 → Network 面板，正常使用几分钟，绝大多数请求都是 localhost。

详见仓库 SECURITY.md 与 npm run audit。

八、常见问题

别人打不开我的网址？

  • 确认在同一 WiFi（局域网方式）；确认服务窗口还开着；
  • Windows 防火墙放行端口 3210（见第三节第 4 步）；
  • 用 IP 而不是 localhost —— localhost 只对主机自己有效。

「核查」一直失败？

核查要访问外部搜索引擎，网络不通或被限流时就会失败。这不影响其它功能（加新闻、改状态、写备注都可离线用）。

怎么彻底清空、重来？

关掉服务，删掉项目里的 data/ 目录，再启动即可（会重新生成默认账号）。

忘了密码？

删掉 data/ 重来，或用管理员进入「成员模式」重置。

九、版本与校验

发布包附带 SHA256 校验值，用于确认下载到的文件没被中途掉包。

Windows :  Get-FileHash .\news-pool-vX.Y.Z.zip -Algorithm SHA256
macOS/Linux :  shasum -a 256 news-pool-vX.Y.Z.zip

把算出来的值和发布页上写的一致，即说明文件完整。
