# 共享新闻池 · News Pool

> 多人协作的**实时待播新闻池**。每人登录后把准备播的新闻丢进池子，系统**实时去重提示**、**联网交叉核查**，播完打勾。数据全部保存在**你自己的电脑上**，不经过任何第三方服务器。

本地优先 · 零构建 · 开源(MIT) · 一键启动。

---

## 🚀 一键安装（推荐）

**第 0 步：装 Node.js**（只需一次）
到 <https://nodejs.org/> 下载 **18 或更高版本**，一路下一步安装即可。

**第 1 步：启动**

| 你的系统 | 怎么做 |
|---|---|
| **Windows** | 双击项目里的 **`start.bat`**（首次会花一两分钟自动装依赖） |
| **macOS / Linux** | 终端进入项目目录，运行 **`./start.sh`** |

浏览器会自动打开 **<http://localhost:3210>**。把那个黑色窗口关掉即停止服务。

> **不想自己动手？** 把 [`安装提示词.md`](./安装提示词.md) 里的整段话发给你的 AI 编程助手（Codex / Claude Code / Cursor …），它就能帮你装好跑起来。

## 🧭 三种用法（选一个）

一台电脑当「**主机**」，其他人用浏览器访问它 —— **主机配置一次，访客什么都不用装。**

| 用哪种 | 适合 | 访客怎么进 | 成本 | 隐私 |
|---|---|---|---|---|
| **① 局域网** | 同一办公室 / 同 WiFi | 开 `http://主机IP:3210` | 免费 | **最高**（数据不出内网） |
| **② 内网穿透隧道** | 三个人不在同一地方 | 开一个公网网址 | 免费 | 高（自带 HTTPS） |
| **③ 云服务器 VPS** | 要 24 小时在线 | 开固定网址 | 每月少量费用 | 数据在第三方 |

- 详细步骤（含防火墙、HTTPS、安全注意）→ **[部署指南.md](./部署指南.md)**

## ✨ 功能

- **登录 / 独立账号**：每人一个账号，操作可追溯
- **添加新闻**：粘贴链接回车 / 全页拖拽（链接或文字）/ 页面空白处 `Ctrl+V`
- **标题自动提取**：社交链接（X/Twitter）自动取回**推文正文**；普通网页抓 `og:title` / `twitter:title` / JSON-LD / `<title>`；取不到用 URL slug 兜底；也可手动「改标题」
- **🔍 交叉核查真伪**：有文字内容时自动/手动联网搜索**其他来源**的同题报道（DuckDuckGo 主 → Bing 兜底），结果保存到条目并广播给全员；**点击整条新闻**即可展开/收起明细
- **实时同步**（WebSocket）+ 在线人数
- **智能去重**：URL 规范化精确匹配 + 标题精确 + 标题相似度（分词 Jaccard ∪ 中文二元组 Jaccard，≥0.6）+ **候选链接出现在已有条目的核查结果中**
- **重复弹窗**：**忽略** / **提交**（提交＝标为 ★ 重点关注，并向全池广播提醒）
- **状态流转**：待播 / 已播 / 略过（已播记录是谁播的）——条目右侧的**状态胶囊可点**，待播↔已播一键切换，略过点一下恢复待播
- **★ 重点关注**：一键标记"要单开一期/容易漏"的新闻；顶部筛选标签可只看「★ 重点」
- **筛选标签**：全部 / 待播 / 已播 / ★ 重点 / 略过，每个标签带实时数量
- **移动到其他日期**：单条改播出日期；日期分组右侧可一键把该天**未播出的**全部顺延到其他天（默认只移动自己添加的，管理员含全部）
- **📝 备注**：每条新闻都能写主播自己的话（背景介绍 / 你的评价 / 播出时想说的话）——添加时可直接填，之后在 **⋯** 菜单里改；卡片上以琥珀色条单独显示，**备注里的网址可直接点开**，导出与复制都会带上
- **一键复制**：复制「标题+备注+链接」，方便贴到提词器 / 群里
- **导出当天清单**：按人员导出当天条目（☐ 待播 / ✔ 已播 / ★ 重点 / 📝 备注），可复制到剪贴板或下载 `.txt`
- **播出统计**：顶栏「统计」→ 月历网格，逐日查看每人「准备 / 已播」条数；**点击有新闻的某天可直接跳到列表里那一天**
- **🎨 界面外观（10 套）**：顶栏「外观」→ 挑一套界面风格，点一下**立即生效**并记住。内置：经典·暖灰 / 暖调编辑 / 暗夜玻璃 / 工业蓝图 / 战术终端 / 软结构 / 暖金奢品 / 氰版蓝图 / 双色丝网 / 层叠卡片 / 赛博霓虹。**只存你自己的浏览器（localStorage），别人完全不受影响**；不加载任何在线字体（守住"只发 3 类外部请求"的承诺）
- **删除**：删除自己添加的新闻；管理员可删任意条目
- **自定义**：池名称、每个成员的显示名都能随时改
- **成员模式**：管理员密码解锁后可增删成员、改名、清空本池记录
- **每池独立数据库**：`data/pools/<池ID>/news.db`（天然隔离）

## 🎨 自定义

| 想改什么 | 怎么改 |
|---|---|
| **界面左上角的名字（品牌）** | 启动前设置环境变量 `NEWS_POOL_BRAND`，例如：`NEWS_POOL_BRAND="我的频道" npm start`（Windows：`set NEWS_POOL_BRAND=我的频道` 再 `npm start`） |
| **池名称**（顶栏「· xxx」） | 界面右上角 **成员模式 → 本池名称 → 保存** |
| **成员显示名** | 成员模式 → 对应成员点 **改名** |
| **界面外观（10 套风格）** | 顶栏 **外观** 按钮里挑；记在**你自己浏览器**，切换立即生效，不影响别人 |
| **端口** | 环境变量 `PORT`（默认 `3210`） |
| **监听地址** | 环境变量 `HOST`（默认 `0.0.0.0`，局域网可访问） |
| **核查搜索超时** | 环境变量 `NEWS_POOL_SEARCH_TIMEOUT`（毫秒，默认 `8000`） |
| **默认账号/密码** | 成员模式里改；或删掉 `data/` 目录重新初始化（会清空数据） |

## 🔒 隐私与安全（无后门声明）

这个项目**源码完全开放**，所有逻辑都在 `src/` 里，可逐行检查：

- **数据全部存在本地**：新闻、账号、密码（bcrypt 哈希）都写在 `data/` 目录里，**不会上传到任何服务器**，没有埋点、没有遥测、没有账号体系外联。
- **唯一的外部网络请求**只有三处，且都是你主动触发的：
  1. 添加网页链接时抓取网页标题；
  2. 点「核查」时用公开搜索引擎（DuckDuckGo / Bing）搜索同题报道；
  3. 添加 X/Twitter 链接时取回推文正文（fxtwitter / oEmbed）。
- **不存在任何“把数据发回作者”的代码。**

**想自己核实？** 跑一句自查脚本，它会打印出全部依赖、源码里**所有**外联点、以及危险模式检查：

```bash
npm run audit
```

详细的自验方法（断网测试、`F12` 看网络请求）见 **[SECURITY.md](./SECURITY.md)**。

> 建议：仅在内网使用；若要暴露到公网，请先改掉默认密码并加 HTTPS（见 [部署指南.md](./部署指南.md)）。

## 🧪 如何测试（3 个浏览器窗口）

1. 打开 3 个窗口（其中一个用无痕模式，避免登录串号），分别登录 alice / bob / carol。
2. 任一窗口粘贴一个链接回车 → 其他窗口**实时**出现该条目。
3. 换一个窗口添加**同一个链接** → 立刻弹红色「疑似重复」并提示是谁加的。
4. 一个窗口点条目右侧的「待播」状态胶囊 → 该条变「已播」（再点一下变回「待播」）；此时再加同链接会提示「已被 X 标记播出」。
5. 右上角「成员模式」→ 输入 `admin888` → 可改池名、改成员名、增删成员、清空记录。
6. 点条目上的 **☆ 标重点** → 上方「★ 重点」标签能看到它；条目右侧只留「状态胶囊 / ☆标重点 / ⋯」，其余操作（改标题 / 核查 / 略过 / 移动日期 / 复制 / 删除）都在 **⋯** 菜单里；日期分组右侧可把当天未播出的整体顺延。
7. 顶栏 **统计** → 月历网格，确认每天的「准备 / 已播」数。
8. 顶栏 **外观** → 挑一套风格（如「暗夜玻璃」「赛博霓虹」）→ 界面立即变样；刷新后仍是你选的；换个浏览器 / 无痕窗口仍是默认（各人各选）。

```
news-pool/
  start.bat / start.sh   一键启动脚本
  安装提示词.md            复制给 AI 助手即可自动安装
  README.md               本文件
  SECURITY.md             安全与隐私说明（怎么自证没后门）
  部署指南.md              局域网 / 隧道 / VPS 三种部署
  给访客的一页纸.md         发给用的人看的说明
  THIRD-PARTY-NOTICES.md  第三方组件与素材许可清单（含免责说明）
  docs/使用手册.html       使用手册（可 npm run manual 打成 PDF）
  scripts/
    audit.cjs   无后门自查脚本（npm run audit）
    publish.cjs 一键发布脚本（npm run release）
    manual.cjs  把 docs/使用手册.html 打成 PDF（npm run manual）
  src/
    server.js    HTTP 服务 + REST + WebSocket 广播
    db.js        池注册表 + 每池 SQLite + 用户/会话/条目
    dedup.js     URL/标题规范化、相似度、标题抓取
    search.js    联网搜索（核查其他来源）：DuckDuckGo Lite → Bing
    social.js    社交链接展开：X/Twitter 取回推文正文（fxtwitter → oEmbed）
  public/        前端（无构建：index.html / app.js / style.css）
  verify/        冒烟测试
  design-preview/ 界面外观设计稿（静态 HTML，非应用运行时；会加载在线字体）
  data/          运行时生成：pools.json + pools/<id>/news.db（已 gitignore，勿提交）
```

## ⚠️ 部署到公网（进阶）

完整三种部署方式见 **[部署指南.md](./部署指南.md)**。直接暴露公网前，务必至少做到：

- 用 Nginx/Caddy 加 **HTTPS** 反向代理，并开启访问认证；
- 修改全部默认账号与 `admin888`；
- 加限流（核查会请求外部搜索引擎，可能被限流）；
- 定期备份 `data/` 目录。
